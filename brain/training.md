# Training Plan

**Goal:** Strength + hypertrophy — slow lean bulk
**Stats:** 1.86 m / ~82 kg → target 85-87 kg
**Frequency:** Push / Pull / Legs (once each) + 2 swims/week

## Weekly Schedule

| Day | Session |
|-----|---------|
| Monday | 💪 Push Day |
| Tuesday | 🏊 Swim |
| Wednesday | 💪 Pull Day |
| Thursday | Rest |
| Friday | 🦵 Legs Day |
| Saturday | 🏊 Swim |
| Sunday | Rest |

## Swim Sessions

30-45 min, easy/moderate aerobic pace — not sprint intervals.
If bulk stalls, add food rather than dropping swims.

## Rep Scheme

| Type | Reps | RIR |
|------|------|-----|
| Compounds (bench, pull-ups, rows) | 5-10 | 1-2 |
| Accessories (pulldowns, cable rows, curls) | 8-15 | 1-2 |
| Isolation (lateral raises, flies) | 12-20 | 1 |

## Progression

Double progression on compounds:

```
100 kg bench example:
Week 1: 6 / 6 / 6
Week 2: 7 / 6 / 6
Week 3: 7 / 7 / 7
Week 4: 8 / 8 / 8  → add weight, build back from ~6
```

## Nutrition

- Surplus: +200-300 kcal/day
- Protein: ~150-180 g/day
- Target gain: 0.2-0.4 kg/week

## Notes

- No overhead press needed — bench + incline covers front delts
- Arm volume already high — don't add more; reduce to 2 sets if elbows hurt
- Pull-ups: first 2 sets ~1 RIR, last set to failure
- Seated cable rows: medium/wide grip, let elbows flare to hit upper back
- Removed cable pullover (redundant with pull-ups + pulldowns + rows)
